# Pokémon Card Market Analysis 요구사항

## 승인된 언어 범위

영문판과 일본판 PSA 10을 허용한다. 기존 10종의 각 일러스트를 고정하고, 해당 일러스트의 다른 언어 판본만 후보에 포함한다. Grey Felt Hat Pikachu는 영어판을 유지한다. 신규 일러스트나 카드 수 변경에는 사용자 승인이 필요하다.

판본의 고유 키에는 카드명, 카드 번호, 확장팩, 발행 연도, 언어, 일러스트 식별자 및 유형, PSA 등급이 포함된다. 기존 영어판 ID는 호환성을 위해 유지한다. 판본별로 출처, 거래 건수, 고유 날짜 수, 확보 기간, 데이터 품질과 무료 API 가능성을 비교한 뒤 여건이 나은 판본을 결정한다.

## 기존 분석 범위

- 목표 기간은 2025-01-01~2026-11-25이고, 공통 기간에서 카드 간 비교한다. 종목당 목표 최소 100건, 권장 300~500건이다.
- 판매 완료가 확인된 거래를 분석하며 무료로 허용된 데이터만 사용한다. PSA Auction Prices Realized를 주 자료로, PriceCharting을 교차 검증에 사용한다. 두 신뢰 가능한 출처의 데이터 유형과 거래를 분리하고, 양쪽 거래를 합산하지 않는다.
- 원본과 정제 자료를 분리한다. JPY 거래는 거래일 USD/JPY 근거를 보존해 USD로 변환하며 원본 가격·통화, 환율 날짜·값·출처를 보존한다. 환율 미확인 거래는 제외 사유를 기록한다.
- 일·주·월 중앙값 및 관측 거래량, 7·30일 이동평균, 주·월 및 누적 수익률, 변동성, 최대낙폭, 상관과 유효 표본, 급변 이후 흐름, 출처 비교를 유지한다.
- PCPI에는 기간 전체에서 각 일러스트의 선정 언어판 1종씩 총 10종만 사용한다. 전 종목 주간 중앙값이 있는 첫 기준 주를 100으로 두고 동일 가중 평균을 계산한다. 종목 가격이 빠진 주는 결측으로 둔다. 언어별 비교는 두 판본의 충분한 데이터가 확보될 때 실시한다.
- 한국어 REPORT.md, 재현 가능한 Python CLI, 테스트, 출처 검토 및 데이터 사전을 유지한다. 과제에는 최소 100개 실제 관측, 분석 질문 3개, 기법 2개, 실제 시각화 2개와 수치 인사이트 3개가 필요하다.
- HTTP 403 또는 수집 실패가 발생해도 포켓몬 카드 분석을 지속한다. 접근 제한을 우회하거나 데이터를 만들어 과제 결과를 채우지 않는다.
